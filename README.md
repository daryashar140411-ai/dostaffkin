# Dostaffkin — Angular + исходная принятая работа

В корне находится Angular-проект для публикации на GitHub Pages.

## Сохранность исходной работы

Папка `original-accepted-version/` — отдельная копия исходного принятого проекта (HTML, CSS, JavaScript, изображения и шрифты). Она сохранена как резерв и не используется вместо Angular-приложения. Файлы внутри неё не редактировать.

## Публикация

1. Создайте свой GitHub-репозиторий с именем `dostaffkin`.
2. Загрузите в него всё содержимое этой папки (включая скрытую папку `.github`).
3. В Settings → Pages установите Source: GitHub Actions.
4. После отправки файлов откройте вкладку Actions. Workflow `Build and deploy Angular to GitHub Pages` установит зависимости, соберёт проект в `docs` и опубликует его.

Адрес для репозитория с таким именем: `https://ВАШ-ЛОГИН.github.io/dostaffkin/`.

Если имя репозитория будет другим, измените `baseHref` в `angular.json` на `/<имя-репозитория>/`.
