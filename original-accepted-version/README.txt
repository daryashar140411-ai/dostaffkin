DOSTAFFKIN — ПРОЕКТ С ПОДКЛЮЧЕНИЕМ ЯНДЕКС.КАРТ

ЧТО ПОДКЛЮЧЕНО
- JavaScript API Яндекс.Карт 2.1.
- Геосаджест для подсказок адресов в полях «Откуда» и «Куда».
- Построение автомобильного маршрута и расчёт расстояния по маршруту.
- Демонстрационное оформление заказа и отслеживание по локально сохранённому номеру.

ВАЖНО О КЛЮЧАХ
В этой временной копии использованы ключи, которые владелец проекта передал в переписке.
Они уже были опубликованы, поэтому после проверки обязательно отзовите их и создайте новые.
Новые ключи заменяются только в файле scripts/api-keys.js (поля maps и suggest).
Не публикуйте этот файл вместе с открытым исходным кодом.

КАК ЗАПУСТИТЬ НА WINDOWS
1. Распакуйте весь ZIP в отдельную папку. Не открывайте HTML прямо из архива.
2. Откройте папку проекта в проводнике.
3. Запустите локальный сервер в этой папке (например, расширением Live Server в редакторе)
   либо командой: py -m http.server 5500
4. Если использовали команду, откройте в браузере http://localhost:5500/order.html
   (если проект лежит во вложенной папке dostaffkin_api_work, откройте
   http://localhost:5500/dostaffkin_api_work/order.html).
5. Дождитесь загрузки карты. Введите полный адрес/город в «Откуда» и «Куда»,
   выберите подсказки из выпадающего списка и нажмите «Рассчитать».
6. Если карта не появляется, проверьте в Кабинете разработчика, что для ключа разрешён
   localhost (или домен сайта), что ключи относятся именно к JS API 2.1 и Геосаджесту,
   а после изменения ограничений прошло до 15 минут.

ОГРАНИЧЕНИЯ УЧЕБНОЙ ВЕРСИИ
- Маршрут рассчитывается Яндекс.Картами при доступности API и корректных адресах.
- Заказы не отправляются на сервер: они хранятся в localStorage этого браузера.
- Отслеживание показывает демо-данные, а не реальные перемещения курьера.

ДОБАВЛЕНО ПО ЗАМЕТКАМ ПРЕПОДАВАТЕЛЯ
- День 3: блок выбора скорости доставки расположен перед кнопкой расчёта.
- День 3: используются иконки regular.svg и fast.svg из images/icons.
- День 3: добавлены стили карточек обычной и приоритетной доставки.
- День 4: обе группы карточек (размер и скорость) переключаются; смена выбора сбрасывает прежний расчёт.
- День 4: приоритетная доставка увеличивает итоговую стоимость на 15% и сокращает срок на 30%; выбранная скорость записывается в объект заказа.

В проекте сохранены предыдущие страницы, оформление, карта, подсказки адресов и демонстрационное отслеживание.
